# 원격지원 진단 툴킷 — 단일 파일 PowerShell

> 원격 세션(AnySupport)으로 교사 PC에 보내 실행하는 1차 진단·정리 도구.
> v3.6.20 · 약 5,200행 · 외부 모듈 의존성 없음 · Windows 10/11, PowerShell 5.1, 관리자 권한

> ⚠️ 공개용 사본입니다. 교사 실명·계정 ID·PC명·고객사명·서비스 도메인은 플레이스홀더(`교사A`, `teacher0000`, `LMS`, `lms.example.com` 등)로 바꿨습니다.

---

## 왜 만들었나

원격지원 처리 이력을 분류해 보니 원인이 소수에 몰렸습니다 — 보안 프로그램 충돌, 브라우저 설정·확장, 가상카메라 드라이버, 버전 고정이 필요한 업무 에이전트, 시간 동기화(OTP). 같은 판단을 매번 손으로 반복하지 않으려고 고정된 순서의 점검 도구로 만들었고, 실제 케이스가 들어올 때마다 버전을 올렸습니다. 변경 근거는 스크립트 헤더(`v2.x` ~ `v3.6.20`)에 실측 기록으로 남아 있습니다.

## 설계에서 고민한 것

1. **이름 기반 탐지의 한계 → 탐지 축 추가.** 패턴 목록은 목록에 없는 걸 못 잡습니다. 느림 진단은 이름이 아니라 **프로세스별 활성 TCP 연결 수**로 순위를 매겨 미등록 업로더·토렌트를 드러냅니다.
2. **보존 목록이 제거 목록보다 먼저.** 파일 암호화 도구처럼 "보안 프로그램처럼 보이지만 지우면 복구 불가"인 것은 `$ProtectMap` 에 먼저 걸려 `[보존]` 으로만 표시됩니다. OTP(Authenticator) 확장은 ID 화이트리스트로 삭제 금지.
3. **확실한 것만 실행, 애매한 것은 사람에게.** 백신 비활성화·장치 삭제·재부팅은 안내만.
4. **IP는 기본 게이트웨이 있는 어댑터에서.** 첫 어댑터를 집으면 WSL2/Hyper-V 가상 어댑터(172.x)가 잡히는 실측 사례가 있어 라우트 메트릭으로 정렬.
5. **선생님 세션만 건드린다.** 브라우저 종료 시 세션을 식별 못 하면 모든 세션 브라우저를 닫지 않고 중단 → 사람이 확인.
6. **대상 PC에 흔적을 덜 남긴다.** 트랜스크립트는 `%TEMP%`, 종료 시 자기 삭제(실행 중인 자신은 지연 삭제).

## 파일

| 파일 | 설명 |
|---|---|
| `Remote-Support-Toolkit.ps1` | 툴킷 본체 |
| `Run-Toolkit.bat` | 폴더에서 최신 `Remote-Support-Toolkit*.ps1` 을 찾아 관리자 권한으로 실행 (CP949) |
| `Build-SingleFile.ps1` | `.ps1` 을 단일 `.bat` 배포본으로 빌드. `deploy-blocklist.txt` 의 단어(실명·계정 ID 등)가 배포본에 남으면 **빌드 실패** |
| `deploy-blocklist.example.txt` | 금지어 목록 예시 (실제 목록은 커밋하지 않음) |
| `Camera-Diag.ps1` | "업데이트 후 카메라 안 됨"을 층위별(드라이버·개인정보 설정·점유 앱·브라우저 권한 등)로 가르는 조회 전용 진단 |
| `LectureChannel-Diag.ps1/.bat` | 강의 재생 불가 점검 — 플레이어/에이전트 버전·포트 응답 (조회 전용) |
| `Check-Program.ps1` | "이거 지워도 되나?" 판별 — 게시자·레지스트리 키·언인스톨러 유무로 정체 확인 (조회 전용) |

## 실행

```powershell
# 관리자 권한 PowerShell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\Remote-Support-Toolkit.ps1
```

조회 위주 도구입니다. 표의 **실행** 항목만 시스템을 변경하며, 제거 동작은 되돌릴 수 없습니다. 테스트 PC에서 먼저 확인하세요.
